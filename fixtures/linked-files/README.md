# Synthetic linked-file example

Open **linked-test.ftp.json** in the updated editor. Select **Heptane pan, 1 ft
square** to see the reconstruction plots; select **GoPro** to see the video link.
In the desktop app, **Open** uses the default program and **Show in folder** reveals
the original file in Explorer. Move this folder as a unit to keep its links working.

`volumes.csv` is an independent synthetic large run generated by
`tools/build_synthetic_flame.py`: 100 samples at 2 s from 0 to 198 s, on a 200³
grid at 10 mm with two illustrative valid views. A coarse box model represents
a broad two-view hull, peaking at 2,028,915 occupied voxels (2.028915 m³).
No voxel files are distributed for this run. The generator docstring defines all
20 CSV columns; this CSV is separate from its synthetic 80 kW flame sequence.

`video_example.mp4` is a 6 s, 640×360 H.264 test pattern with no audio, captioned
“FireTestPlanner synthetic example video”. Its assignment to GoPro demonstrates
linking only; it does not claim camera provenance or synchronization with the CSV.

Regenerate both synthetic CSVs and the flame frames with
`python tools/build_synthetic_flame.py`, then rebuild this demonstration plan with
`python tools/build_linked_fixture.py` from the repository root. The browser and
Python tests validate it and check identical canonical serialization. These scripts
preserve the video; they do not generate or overwrite it.
